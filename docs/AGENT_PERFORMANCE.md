# Narrated performances

[Home](../README.md) · [Agent connection](CONNECT_AGENT.md) · [Example script](../examples/vaelari_performance.json)

Use `valkyrie-perform` for a video in which an agent supplies voice lines and head directions. Start Studio, load the model, configure an ElevenLabs or OpenAI voice, and leave Studio running. Copy the example JSON to your own script. Run `valkyrie-perform --script script.json --output new-video.webm` from the package folder. Add `--validate` to check script shape without generating speech or recording.

The script accepts `provider` (`elevenlabs` or `openai`), optional `model_path`, even `width`/`height`, `fps`, `view` (`zoom`, `x`, `y`), `chapter_seconds`, `lead_in`, `tail`, and 1–1000 `lines`. Each line needs `text`; optional fields are `voice`, `tts_model`, `emotion`, `pause`, `motion`, and `audio`. `pause` defaults to **0.18 seconds** after that line, including the final line. For the closest natural joins, use 0.12–0.22 seconds and keep lead-in/tail at zero. A line's `audio` can point to a local WAV/MP3 instead of spending TTS credits; `text` is still required as its script label.

A `motion` cue uses `at` from 0.0 to 1.0 across that line's measured audio, plus yaw/pitch/roll in degrees. Studio interpolates between cues and fades head motion through the short pause. If omitted, it adds subtle default movement. Mouth motion follows the audio, so do not put jaw or mouth parameters in head cues. The runner prepares every line, trims obvious edge silence, composes audio for each chapter, starts recording and audio together, sends head tracking at 20 Hz, waits for the final encode, and joins chapter files into one video. The working folder next to your output keeps prepared WAV and chapter files for inspection. Choose a fresh output path for another run.

For `.mp4` use an FFmpeg build with `utvideo` and `libx264`; `.webm` needs `utvideo` and `libvpx-vp9`; `.mov` needs `utvideo` and `prores_ks`. Export may take longer than playback time. The runner reports a failed chapter rather than silently truncating the video. On the Windows test workstation, a four-line, two-chapter WebM was checked end to end; longer runs remain unverified. See [Validation](../VALIDATION.md).
